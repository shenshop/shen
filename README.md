# SHEN — інтернет-магазин взуття

Next.js-сайт: каталог, сторінка товару, корзина, оформлення з Новою Поштою та Укрпоштою, замовлення одразу в KeyCRM, Facebook Pixel з UTM-мітками.

## Як додавати товар

Товари ведуться в **KeyCRM** (розділ «Товари»), сайт забирає їх автоматично:

1. KeyCRM → Товари → Додати товар.
2. Назва, опис, категорія, фото (перше фото стає головним).
3. Варіанти: властивість **«Розмір»** (36, 37, 38…), ціна і залишок для кожного.
4. Стара ціна для знижки: користувацьке поле товару «Стара ціна».
5. Збережіть. Протягом години товар зʼявиться на сайті. Щоб одразу: відкрити `/api/revalidate?secret=ВАШ_СЕКРЕТ`.

Товар без фото або без жодного варіанта на сайт не потрапляє. Архівні товари ховаються.
Моделі для реклами на головній: `FEATURED_PRODUCT_IDS=101,103,201` (ID товарів у KeyCRM).

## Як змінити телефон, соцмережі, месенджери

Усе в одному файлі `data/settings.ts`: телефон, графік, Instagram, TikTok, Facebook, Viber, Telegram, WhatsApp, email.
Щоб прибрати кнопку, залиште порожні лапки `""`. Після збереження в GitHub сайт оновиться сам за 1-2 хвилини.

## Запуск

```bash
npm install
cp .env.example .env.local   # заповнити ключі
npm run dev                  # http://localhost:3000
```

Без `KEYCRM_API_KEY` сайт показує демо-каталог, а замовлення лише пишуться в лог.

## Звідки брати ключі

- `KEYCRM_API_KEY`: KeyCRM → Налаштування → API.
- `KEYCRM_SOURCE_ID`: ID джерела «Сайт 2» (зараз 13).
- `KEYCRM_NOVAPOSHTA_ID`, `KEYCRM_UKRPOSHTA_ID`: ID служб доставки «НП» (4) та «Укрпошта ФОП» (3).
- Ці три номери записані у `wrangler.jsonc` → `vars`. Ключ `KEYCRM_API_KEY` лежить у Cloudflare як секрет: і для роботи сайту, і для збірки.
- `NOVAPOSHTA_API_KEY`: кабінет Нової Пошти → Налаштування → Безпека.
- Facebook Pixel ID: у `data/settings.ts` (поле `facebookPixelId`). Події: PageView, ViewContent, AddToCart, InitiateCheckout, Purchase.

## Як працює замовлення

Покупець обирає розмір → корзина → оформлення (імʼя, телефон, Нова Пошта з пошуком міста і відділення або Укрпошта з індексом, оплата при отриманні або передоплата). Сервер перераховує ціни за каталогом і створює замовлення в KeyCRM разом з UTM-мітками реклами. ТТН створюється в KeyCRM.
Кнопка «Швидке замовлення» на товарі: тільки імʼя і телефон, менеджер передзвонює.

## Хостинг

Основний варіант: **Cloudflare Workers, безкоштовний тариф** (100 000 запитів на день, комерційне використання дозволене).

1. dash.cloudflare.com → Workers & Pages → Create → Import a repository → `shenshop/shen`.
2. Команди лишити стандартні: Build `npm run build`, Deploy `npx wrangler deploy` (скрипт збірки сам бачить Cloudflare).
3. Settings → Variables and Secrets: додати ключі з `.env.example`.
4. Settings → Domains & Routes → Add custom domain → `shen-shop.com.ua`.

Сховища кешу KV (shen-page-cache, shen-tag-cache) вже створені, їхні ID записані в `wrangler.jsonc`.
Локальна перевірка Cloudflare-збірки: `npm run preview`.

Сайт також працює на Vercel без змін (`next build`).
